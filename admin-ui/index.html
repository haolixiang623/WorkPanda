「字段中文名」决定群众页显示什么：不填，页面就把内部字段名（subject）直接印给群众。

识别规则（一句话能不能命中所属事项）

规则随版本一起保存并发布。关键词命中即参与打分，命中越多分越高；槽位抽取只在 规则命中后才跑，用来把群众已经说出口的字段值填进去（抽不到就留空，不会按默认值补齐）。 flow_id / version 取自上方输入框，不单独填写——规则指向别的版本， 会变成「识别命中了、建任务却报未发布」。留空表示这一版不接受一句话直达。

意图样例（发布门禁材料）

样例随版本一起保存，发布时由服务端门禁裁决。正例必须能被识别到本流程这一版； 近似误例与超范围例必须一条都不被路由。样例一律用合成或脱敏话术，不要填入真实用户原话。
